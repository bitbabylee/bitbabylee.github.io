Privacy policy

Last updated: 2026-09-25

freya bogo sign is a personal tool used only by its owner.

What it accesses

With the owner's consent it uses the Google Sheets API to read and write one fixed range (G3:H22) of one spreadsheet the owner can edit. It writes only a ticker symbol and a chart timeframe.

What it stores

The OAuth token is stored only on the owner's own computer. No Google user data is sent to any third party, sold, or used for advertising.

How to revoke

Access can be removed at any time from Google Account settings under Security, Third-party access.
